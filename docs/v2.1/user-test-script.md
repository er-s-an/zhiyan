# V2.1 用户测试脚本（Gate A / M5）

> 目的：验证用户打开决策简报后，能否在 2 分钟内说出机会、证据与下一步；不是让用户评价 UI 好不好看。

## 对象

5–8 名：独立开发者、一人公司创始人、小团队产品负责人、产品经理或咨询顾问。至少 3 人做过“开发前判断”。

## 任务（不教学）

1. 打开 `main-case-decision-brief.html` 或应用内 `/workbench?demo=main-case`。
2. 给 2 分钟自由阅读，不解释页面。
3. 关闭页面，回答：
   - 这个产品想法原本是什么？
   - 讨论让它发生了什么变化？
   - 如果只能先验证一个机会，你会选哪个？为什么？
   - 哪条证据最重要？能回到原文吗？
   - 下一步你会做什么？什么情况下会停？
4. 再打开页面，让用户指出他刚才说的内容来自哪里。

## 观察指标

- 2 分钟内说出至少一个“原来没想到”的角度；
- 能指出至少一条支持证据和一条反例/条件；
- 能说出下一步验证，而不是只说“再搜搜”；
- 不需要研究术语解释就能理解；
- 能区分“原文直接说”与“AI 推断”。

## 判定

- 5/8 能完成 3 个以上问题 → Gate A 通过；
- 多数人只记住样本数/术语 → 信息层级不通过，先改简报，不扩功能。
