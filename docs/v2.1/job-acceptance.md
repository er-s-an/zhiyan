## 失败恢复实现

- 任务状态：`queued / running / completed / failed`。
- 失败时保留已完成轮次快照和 `stage`，页面显示错误与“重试”。
- 重试复用同一任务的搜索缓存；已完成的查询不会再次调用知乎接口。
- 未在验收中强制制造一次失败；该路径为代码级实现，外部部署环境仍需联调。

## 已知限制

- 当前任务存储在 Node 进程内存；`next start` 单进程可验收，重启进程会丢失运行中任务。
- 部署到 Vercel 等无状态/短函数环境时，需要把任务执行迁移到队列/独立 worker；页面和 API 形状已按可迁移方式拆分。
