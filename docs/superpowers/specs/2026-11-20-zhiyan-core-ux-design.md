# 知研台核心路径 UI/UX 优化设计

## 目标与约束

优化首页、访谈结果、研究台和落地方案的信息层级与用户路径，让首次用户能选对入口，让完成研究的用户立即看到下一步。保留知乎蓝白视觉与现有组件风格，不做全站换肤。

本轮不修改研究算法、访谈评分逻辑、数据结构、API 或多语言业务词典；新增及改写的界面中文沿用现有 `pickLang` / `t` 模式提供英文回退，法、日、俄、韩继续走既有回退规则。

## 已确认问题

- 首页主 CTA 只回到首页，4 问澄清和完整访谈缺乏清晰入口；移动端首屏看不到主动作。
- 访谈结果把分数和八维度置于主要行动之前，主要 CTA 位于长页后部。
- 研究台重复展示简报标题与建议，落地方案缺少直接出口。
- 落地方案重复项目标题与长段定位，5 个操作同层级，“接下来 7 天”位于页面末尾。
- 辅助文字 `#8590a6` 在白底对比度约 3.21:1；移动端研究搭子遮挡正文。

## 页面设计

### 1. 首页与全局导航

首页提供两条主要路径：

1. **我还没想清楚：4 问快速澄清**。通过自定义 UI 事件打开研究搭子并进入既有 `startClarify`，不复制澄清逻辑。
2. **我已有明确 Brief：直接生成研究计划**。滚动并聚焦现有 Brief 输入区。

完整 11 题访谈作为需要系统评估的第三入口。压缩首屏 Hero 文案，主案例和方法说明下移；窄屏首屏能看到主动作。

主导航保留首页、访谈、研究台、方案四个核心入口，示例和产品说明降为页脚入口。顶部 CTA 根据是否已有访谈结果显示“开始访谈”或“继续方案”，链接到 `/interview` 或 `/action-plan`。访谈页和研究搭子继续沿用现有状态恢复。

### 2. 访谈结果

内容顺序改为：

1. 初判结论与简洁摘要。
2. 必须验证的关键假设。
3. 主要行动：生成研究计划；次要行动：查看落地方案。
4. 主要风险与下一步。
5. 八维度详情和完整访谈记录。

分数降为辅助参考，不再是首屏最大元素；八维度默认折叠。保留“这是研究初判，不是可行性结论”的边界说明。访谈聊天流程本轮不改问题和评分。

### 3. 研究台

移除外层重复的“产品决策简报”标题与重复建议标签，保留真实决策问题、三格速览和第一机会卡。顶部操作调整为“查看落地方案”主出口、“调整计划”和“导出”次操作。若尚无完成访谈，落地方案页继续显示既有空状态并引导先访谈。

移动端压缩缓存提示、标题区和非关键标签，让决策问题及速览更早出现。保留研究过程、证据与质检三个视图及现有重算逻辑。

### 4. 落地方案

内容顺序改为：

1. 一句话定位与首个切入人群。
2. 接下来 7 天。
3. MVP 做、验证后再加、现在不做。
4. 12 周路线图。
5. 实验、商业模式、证据与风险细节。

定位长文恢复正常正文字号，不再以大号粗体重复页面标题。顶部操作收敛为一个主动作、一个次动作和“更多操作”折叠区；本地模型润色、调整研究计划、重新访谈放入次级区域。长内容用原生 `details` 折叠，默认保留 7 天行动和 MVP 展开。

### 5. 可读性与移动端

- 辅助文字颜色调整到白底普通文本对比度至少 4.5:1 的色值。
- 小屏研究搭子 launcher 收为圆形图标，保留可访问名称；主内容增加底部安全间距。
- 手机芯片与按钮增加点击区域，保持桌面布局不变。
- 新折叠控件使用原生 `details/summary`，键盘可操作，焦点样式保持可见。

## 组件与事件边界

- `AppShell` 只负责核心导航与顶部入口，不读取研究业务数据；访谈完成状态通过既有 localStorage 摘要读取，挂载后更新以避免 SSR 不一致。
- 首页通过 `window.dispatchEvent(new Event("zhiyan:clarify"))` 请求打开澄清；`InterviewDock` 监听后设置 `open` 并调用既有 `startClarify`。卸载时移除监听。
- 页面区块重排尽量移动既有 JSX，不复制领域逻辑，不改变 localStorage key。
- 样式集中追加到 `app/v2.css` 的对应组件区，避免内联样式继续增加；旧样式仅在有明确新类替代时删除。

## 验证

1. 既有 `npm test` 全部通过，`npm run build` 通过。
2. 为首页澄清事件、导航和结果页顺序添加与现有测试风格一致的前端静态验收脚本；不引入新依赖。
3. 用 ego lite 在真实浏览器走通：首页 4 问澄清、Brief 入口、11 题访谈结果、研究台到落地方案。
4. 在 1450×731 和 375×667 检查首页、访谈结果、研究台、落地方案；首屏主动作可见，无横向溢出，launcher 不遮挡正文。
5. 检查 `details` 键盘操作、导航当前页状态、本地状态恢复，以及研究台证据排除后的既有重算行为不回退。
